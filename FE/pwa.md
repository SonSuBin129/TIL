### PWA란?

PWA란 Progressive Web Apps의 줄임말로, 모바일 기기에서 Native App과 같은 사용자 경험을 제공하는 웹앱이다.<br/>
기존의 전통적인 웹앱과는 달리 네이티브 앱과 유사한 기능을 제공할 수 있다는 것이 가장 큰 특징임.

**장점**

- 오프라인에서도 작동 가능<br/>
  웹 페이지가 로딩되는 동안은 오프라인에서 캐시된 데이터를 사용하고, 네트워크 연결이 되면 새로운 데이터를 불러와 업데이트 함.
- 앱을 다운로드하거나, 업데이트할 필요 없이 웹 브라우저를 통해 앱을 바로 사용할 수 있음
- 네이티브 앱과 마찬가지로 푸시 알림 기능을 제공하고, 카메라, 마이크 등 모바일 기기 자체의 기능도 사용할 수 있음.
- PWA는 AOS, iOS 모두 호환이 가능함.
  <br/>

**단점**

- 아직 모든 기능이 네이티브 앱과 같지는 않다.
- 브라우저에서 실행되기 때문에 네이티브 앱에 비해 지연속도가 크고 배터리 소모량이 더 많을 수 있다.
